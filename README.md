Welcome to my personal engineering portfolio repository! I am a third-year **Engineering Science (Aerospace Engineering)** student at the University of Toronto. This repository holds the source code for my portfolio website, built entirely from scratch using pure HTML, CSS, and Vanilla JavaScript. 

You can view the live website here: [sailorroon.github.io/portfolio](https://sailorroon.github.io/portfolio/)

---

## 🌟 Key Features

*   **Single-Page Architecture:** Smooth, JavaScript-driven section transitions without jarring page reloads.
*   **Dynamic Media Galleries:** Custom-built image galleries with smart aspect-ratio detection (automatically scrolls horizontally or vertically based on the image's natural dimensions).
*   **Coursework Repository:** Detailed breakdowns of UofT Engineering courses, including downloadable notes, labs, and cheat sheets.
*   **Interactive UI Elements:** Hover effects, dynamic thumbnail selections, and a walking Kirby easter egg in the footer!

## 📁 Repository Structure

*   `index.html`: The core structure and content of the single-page application. Includes all inline CSS and vanilla JavaScript logic.
*   `/images`: Contains all graphical assets, project thumbnails, and course note previews.
*   `/files`: Hosts all downloadable content, including PDF course notes, project reports, design calculations, and my full professional resume.
*   `/gifs`: Home to animated assets (e.g., the footer animation).

## 🛠️ Technologies Used

*   **Frontend:** HTML5, CSS3 (Flexbox, Grid, CSS Animations)
*   **Logic:** Vanilla JavaScript (ES6)
*   **Hosting:** GitHub Pages
