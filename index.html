Evaluation of Haptic and Visual Cues in Maze Navigation Tasks

Maze Navigation Task In Python

Project Report
Project Proposal
Maze Code Github

Project Partners

This project was a course work for MIE286, in which I collaborated with Oscar Low and Oscar Liang.

Project Overview

The project involved picking a specific task and investigating the effects of external influence on the given task.

To achieve this, our team designed a maze game on python, feedback happens whenever the subject touches the wall. Additionally, we also developed a vibrating app on Android that provided haptic feedback. The visual feedback was inplemented by the maze game's code itself.

Our team invited 48 students in total and divided them into 2 groups. One group with visual feedback and the other with haptic feedback. We then recorded their time spent to finish the maze (speed) and the time spent touching the maze's wall (accuracy).

Though no significant relations were established, this provided a fundamental understanding in actual statistical experimental setup.

Skills Applied

  • R: Data analysis and visualization.
  • Python: The programming language used for developing the maze game.
  • Experimental Control: Ensuring consistent and reliable experimental procedures.

(Hopes and Prayers) Matboard Bridge

Our team holding the bridge on testing day

Design Calculations Design Report Engineering Assembly One-pager MATLAB Code

Project Partners

This project was a course work for CIV102, in which I collaborated with Paul Choi, Dylan Setyono and Atharv Kudchadkar.

Project Overview

This project involved using MATLAB and physical calculations to iterate and design a bridge that can support the most load.

Our team repeated checked for safety parameters such as tension/compression/buckling/shear etc.

After the design phase, we physically built the bridge out of matboard + concrete glue.

We then tested the bridge by adding weights until it collapsed, and recorded the maximum load it could support, in our case it was 430N!

This project served as a stepping stone into practical civil engineering work. It also helped bridge the gap between civil engineering knowledge and application.

Side note, this was called Hopes and Prayers as we needed hopes and prayers for it to not fail!

Skills Applied

  • MATLAB: The code for structural analysis, bending moment diagrams, and shear force diagrams.
  • Hands on building: Planning, Constructing the bridge model, especially reinforcing the connections with glue.
  • Documentation, Calculations: Writing up the project report and performing necessary calculations.
